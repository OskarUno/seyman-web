# Despliegue en Cloudflare Pages

Este sitio es estático y no necesita proceso de compilación.

## Configuración recomendada

- Repositorio: `OskarUno/seyman-web`
- Rama de producción: la rama principal del repositorio
- Framework preset: `None`
- Build command: dejar vacío
- Build output directory: `/`

## Dominio

En Cloudflare Pages, abrir el proyecto y entrar a **Custom domains**. Agregar primero `seyman.cl` y después `www.seyman.cl`. La configuración DNS debe realizarse únicamente cuando la versión final esté aprobada.
